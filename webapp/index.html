PyInsect Data Collector

Put an insect on the turntable and plug the turntable into this device with USB. The app spins the insect, changes the lighting and takes the photos for you.

  1. Step 1 · Capture Press Capture Dataset. The turntable spins while the lighting changes automatically, and 500 photos are taken in 8 seconds. Use the slider to change the time.
  2. Step 2 · Review When it's finished you'll see a gallery of every photo that was taken. Tap a photo to remove it.
  3. Step 3 · Name Give the folder the insect's name and save it.

Not connected

Pressing Capture Dataset asks you to pick the ESP32's serial port the first time. After that it reconnects automatically.

Calibrate turntable

A 360° servo doesn't know its position, so it turns for a set time. Press Spin 360°. If it turns too far, lower the time. If it stops short, raise it. Then press Save.
